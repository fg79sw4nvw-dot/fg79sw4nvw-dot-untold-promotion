# UNTOLD 公式アカウント台帳

このページは、UNTOLDのプロモーション運用で使用する公式アカウントと連絡先の**非機密情報のみ**を管理する。

## セキュリティ境界

このリポジトリには以下を保存しない。

- パスワード
- パスキーの秘密情報
- 2段階認証 / MFA の秘密鍵・セットアップキー
- バックアップコード / 復旧コード
- 再設定用メールアドレスの具体値
- 電話番号
- セッショントークン、APIキー、Cookie、その他の認証情報

これらはGitHubやChatGPTではなく、パスワードマネージャー等の安全な保管先で管理する。

## 今後の追記ルール

新しい公式アカウントを作成した場合は、必要に応じて以下を記録する。

- サービス名
- アカウント名 / ハンドル
- メールアドレス（機密性が低く、記録が必要な場合のみ）
- 用途
- 公開 / 非公開
- 作成済み / 未作成
- 作成日
- 他アカウントとの役割関係

認証情報は記録しない。

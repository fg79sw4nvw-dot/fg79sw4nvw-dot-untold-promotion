# UNTOLD 情報レイヤー・導線方針

## 状態

確定: 全プロモーション運用に適用する上位方針

## 目的

UNTOLDそのものの収益化は目的としない。
UNTOLDを代表作・実績・接点として、将来的に創作・制作活動によって継続的に生活を支えられる状態へつなげることを長期目標とする。

そのため、SNS、公式サイト、紹介文、固定投稿、メイキング、インフルエンサー施策、問い合わせ導線、完成後の発信など、今後のプロモーション運用では以下の情報レイヤーを基本構造として使用する。

## 情報レイヤー【確定】

### 第1層: UNTOLDという作品

最初に見せるものはゲームそのものとする。
世界、探索、カード、人物、謎、ビジュアル、ゲーム体験を入口にし、まずUNTOLD自体への興味を作る。
HUNTER×HUNTERやAIを作品より前面に出して、作品の第一印象をそれらだけで規定しない。

### 第2層: HUNTER×HUNTERへの愛・影響・リスペクト

UNTOLDがHUNTER×HUNTER、とくにグリードアイランド等から強い影響を受けて制作されていることは意図的に隠さない。
作品に興味を持って一段深く見た人が、影響源と制作動機を明確に確認できる状態を作る。

単なる類似点の列挙ではなく、何に魅力を感じ、何を研究し、どのようにUNTOLD独自の世界・仕組み・遊びへ再構成したかを伝える。
HUNTER×HUNTERへの愛と理解が、ゲーム本体とプロモーションの双方から自然に感じられる状態を目指す。

プロモーション依頼では、UNTOLDがHUNTER×HUNTERを強いモチーフ・影響源としていることを必ず相手へ明示する。
ただし、公式作品・公認作品・二次創作作品であるとの誤認を招かないよう、独立したオリジナル作品として扱う。

### 第3層: AIと制作しているという背景

AIを使用して制作している事実を隠さない。
一方で「AIゲーム」であること自体を最上位の売り文句にはしない。

基本的な見せ方は、作品と制作動機を知った人が、その次の段階で「実はかなりAIと一緒に制作している」と分かる程度とする。
AI使用の事実は比較的早い段階で到達できる情報として配置する。

ここではまずAI利用の事実と大まかな制作背景を伝え、詳細な制作手法は後段で扱う。

### 第4層: 世界・物語・伏線・ゲームデザイン

設定密度、伏線、情報開示、真相、NPC、カード、土地等が相互に接続していることを見せる。
さらに、それらを探索、記録、推理、条件達成、カード化、収集等のゲームプレイへ変換している設計を示す。

この層では、UNTOLDが単なるHUNTER×HUNTERの模倣でも、AIによる自動生成物でもなく、意図的に設計された独自作品であることを作品そのものによって示す。

### 第5層: AI制作方法・IP構築

第3層で示したAI利用を、ここでは制作能力として深掘りする。
仕様の正本管理、確定・未確定の分離、AIによる勝手な補完の禁止、設計・実装・検証・修正・監査等、AIを制作工程へどう組み込んだかを必要に応じて公開する。

同時に、ゲーム本体だけでなく、世界、キャラクター、カード、UI、ビジュアル、SNS人格、情報公開、プロモーションまでを一つのIPとして構築した過程も制作実績として扱う。

### 第6層: できること・次への接点・CONTACT

最深部では、UNTOLDによって実証した能力を次の5本として整理する。

1. HUNTER×HUNTERへの深い理解と再構成力
2. 世界・物語・伏線を高密度に設計する能力
3. AIクリエイターとしての制作能力
4. ゲームデザイン能力
5. IPを一つの作品として立ち上げる能力

そのうえで、制作、企画、HUNTER×HUNTER関連、ゲーム、AI活用、共同制作、取材その他の仕事・協業につながる問い合わせ先を用意する。
制作者個人のSNSアカウントは現時点では設けず、外部からの直接コンタクトは指定メールアドレスへ集約する。

## 導線の要約

UNTOLDという作品
→ HUNTER×HUNTERへの愛・影響
→ AIと制作しているという背景
→ 世界・物語・伏線・ゲームデザインの密度
→ AI制作方法・IP構築
→ できること・次への接点
→ CONTACT

言い換えると、

**作品 → 動機 → 制作背景 → 設計力 → 制作能力 → 実績 → 仕事**

の順で情報を深くしていく。

## 運用への適用ルール【確定】

- この情報レイヤーは特定のSNS投稿だけの構成ではなく、今後のプロモーション運用全体に適用する。
- X、TikTok、YouTube、Instagram等のSNS、公式サイト、プロフィール、固定投稿、紹介文、メイキング、プレス向け説明、インフルエンサー依頼、問い合わせ導線、完成後の制作記録を設計する際の共通基準とする。
- すべての媒体で6層を一度に説明する必要はない。媒体と投稿の役割に応じて必要な層だけを見せる。
- ただし全体として、興味を持った人が第1層から第6層まで自然に辿れる導線を維持する。
- AIについては「隠さないが主役にしない」を維持し、第3層で存在を見せ、第5層で制作能力として深掘りする二段階構造を基本とする。
- HUNTER×HUNTERについては、通常投稿のすべてで名称を出す必要はないが、影響源である事実を意図的に隠さない。特にプロモーション依頼時は必ず明示する。
- HUNTER×HUNTERへの愛は名称や固有表現の直接的な模倣量ではなく、作品理解、ゲーム構造、遊び心、設定密度、情報設計、リスペクトのある発信によって示す。
- 将来の仕事や協業につながる可能性を考慮し、UNTOLD公式は作品アカウントであると同時に、匿名の制作者にとってのポートフォリオとしても機能させる。
- 今後プロモーション施策に迷った場合は、まずこの情報レイヤーとの整合性を確認する。
